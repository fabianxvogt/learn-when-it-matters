03 / CAUSAL CONTRACT

What counts as a fair test?

✓
Predict before labels

Every prediction uses only the current feature and past observed targets.

✓
Probe cost is visible

The gate pays for counterfactual history checks; rejected updates stay in the ledger.

✓
No latent regime IDs

Recurring forcing stays inside the stream generator, hidden from every method.

✓
Held-out work is local

Use the CLI for repeated seeds; this browser run is an instrument, not a final claim.
